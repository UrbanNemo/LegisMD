# Changelog

All notable changes to the Frame Generator plugin for Tekla Structures will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-03

### Added
- Initial project structure and solution setup
- Core plugin entry point and Tekla integration framework
- Windows Forms UI skeleton with main application form
- Tab-based interface for all major feature areas
- Data model classes for all structural elements
- Basic frame spacing generator
- Roof geometry calculation engine
- 2D preview panel control
- Comprehensive project documentation
- Unit test framework and infrastructure
- Installation and setup documentation
- Developer guidelines

### In Progress
- Truss system implementation
- Purlin placement engine
- Bracing pattern generator
- Deck slab integration
- 3D visualization
- Material takeoff reporting

### Planned
- Advanced clash detection
- Template management system
- BIM 360 integration
- Performance optimization for large structures
- Multi-language support
